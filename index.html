    How sets are counted

    A working set counts as 1 set for each primary muscle and half a set for each secondary muscle, so a bench press adds 1 to chest and 0.5 to triceps and shoulders. Warm-up sets are left out.

    Weeks run Monday to Sunday. The default targets are starting points, not prescriptions. Change them to suit your programme.
